# 홀드아웃6 사전등록 — 원본 풀 251~300번

작성일: 2026-08-07

상태: **실행 전**

## 평가 목적

홀드아웃5에서 드러난 `수입물가 → 소비자물가` 표 의미 불일치와 빈
`mapping_type` 문제를 고친 뒤, 아직 보지 않은 원본 풀 251~300번에서
안전성과 실제값 검증 도달률을 한 번만 측정한다.

200건 자동 골드 개발 회귀평가는 별도 작업이며 이 홀드아웃의 독립 평가와 섞지 않는다.

## 고정 입력

- 원본: `data/archive/검증대상_기사드랍후.csv`
- 범위: 1부터 센 원본 행 251~300
- 입력: `data/holdout6_articles.csv`
- 기사 ID 접두어: `H6`
- 기사 수: 50
- 출력: `outputs/holdout6_251_300/`
- 전용 Chroma 경로: `data/indexes/kosis_meta_chroma_holdout6`

기사 내용은 자동 슬라이스 생성 과정에서 출력하거나 사람이 열어보지 않는다. 입력 파일과
실행 번들의 SHA-256은 생성 매니페스트에 고정한다.

실행 전 고정 해시:

- 원본 SHA-256: `56c025b52783f3cde215fbaa4dee1a0b634dc031fe9ac92cf52dd69db7554ffe`
- 홀드아웃6 입력 SHA-256: `ee33db5bbc17760f588c725127f46f86cc8393e00167fa9da6b15c5b2bab8bb7`
- Colab 입력 번들 SHA-256: `863e38eb9e5a00ebd1b0591ebc99a867a9bd3b05634f8628e4b6c04128f98866`
- 기준 커밋: `376f1bb62beedeb4d947037e830034b14d0e45e3`

기준 커밋 이후의 이번 변경은 번들 안 `bundle_manifest.json`의 파일별 해시를
권위 있는 실행 코드 식별자로 사용한다.

## 이번 변경

1. target term을 지역·국가·산업·품목·인구집단으로 제한하고 지표어·시점·최상급 표현을 제외한다.
2. 주장 지표와 표 이름·통계 분야·기관이 충돌하면 `INDICATOR_TABLE_MISMATCH`로 기록하고 `READY`를 `NEEDS_CONFIRMATION`으로 내린다.
3. `value_type=증감률`이고 `change_base`가 `전월` 또는 `전년동월`이면 선택 ITEM으로 `mapping_type`을 복구한다.
4. 직접 비율 ITEM의 비교 기준이 주장과 다르면 확정하지 않는다. 수준값 ITEM이면 `rate_from_level`과 비교기간을 복구한다.

## 실행 전 예측과 판정 기준

### 안전성 — 우선순위 1

- 수입·수출·생산자·소비자 물가지표 계열이 충돌한 후보의 `READY`: **0건**
- target-bearing 주장을 집계 OBJ로 자동 확정한 건: **0건**
- 비교 기준이 다른 직접 비율 ITEM을 자동 확정한 건: **0건**
- 값 `불일치`는 전건 좌표·기간·계산식을 수동 확인하며, 거짓 `불일치`: **0건 목표**

### 구조 복구 — 우선순위 2

- `value_type=증감률` + `change_base∈{전월, 전년동월}`이고 선택 ITEM의 차원을 판정할 수 있는 행에서 `mapping_type` 빈값: **0건**
- 직접 비율 ITEM은 `direct`, 수준값 ITEM은 `rate_from_level`로 나뉘어야 한다.
- `rate_from_level`은 현재 기간과 비교기간 두 시점이 없으면 `READY`가 될 수 없다.

### 실행 무결성

- validate 및 실제값 검증 `API_ERROR`: **0건**. 남으면 결과 판정을 보류한다.
- 기사 50건과 고유 `H6` 기사 ID 50개를 확인한다.
- 확정률은 성공 기준이 아니다. 보수적 보류로 낮아질 수 있다.
- 첫 50건의 기존 일치 사례를 지키는 전체 회귀 테스트가 통과해야 한다.

## 오염 방지

- 홀드아웃6 결과를 본 뒤 이 묶음에 맞춘 규칙 수정이나 임계값 조정은 하지 않는다.
- 실패 원인은 그대로 기록하고, 변경 검증이 더 필요하면 다음 미사용 묶음 301~350번을 사용한다.
- 결과 ZIP에는 API 키, `.env`, 대용량 모델·인덱스를 포함하지 않는다.
