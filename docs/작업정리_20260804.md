## 1. 정밀도를 처음 쟀다 — 그리고 전부 오판이었다

확정 12건 중 `불일치` 3건이 나왔다. **셋 다 기사가 맞았다.** 원인이 각각 달랐다.

| 원인 | 조치 |
|---|---|
| 대상이 문장에 근거 없음 (`전체 수출액` + `item=반도체`) | `claim_item_grounded` — 막지 않고 **지운다** |
| 비교 기준 오독 (`한 달 전(1.4%)` → 전월로) | 추출 프롬프트 규칙 |
| 한계값을 측정값으로 (`2%를 밑돈`) | `THRESHOLD_CLAIM_UNSUPPORTED` — 판정하지 않는다 |
| 범위 밖 주장이 살아남음 (한은 제출자료) | 출처 귀속 전파 |

이 넷을 고쳐 **불일치 0** 을 만들었다. 그리고 마진 게이트를 두 번 측정해
(2-vs-2 → 2-vs-0) 풀어서 확정 12 → 17 이 됐다.

**교훈: 커버리지보다 정밀도가 먼저다.** 참인 기사에 거짓 딱지를 붙이는 것이 최악이다.

## 2. 손으로 패치한 파이프라인을 한 줄기로 되돌렸다

`prepare` 부터 정식 순서로 다시 돌렸다. 재현됐고(확정 17 → 16, 노이즈 범위),
**정식 순서로만 드러나는 버그 둘**을 잡았다.

- **출처 전파가 무력화돼 있었다** — `prepare` 가 출처 문장을 먼저 지워
  `lock` 이 전파할 근거를 잃었다. 전파를 `prepare` 로 옮겼다.
- **대상을 지울 때 한쪽 필드만 지웠다** — `claim_item_grounded` 는
  `measurement_item` 을 먼저 읽는데 `industry_or_item` 만 지웠다. 확정 3건을 잃고 있었다.

**교훈: 같은 규칙을 두 단계에서 돌릴 때는 순서가 결과를 바꾼다.**

## 4. 좌표 모델을 넓혔다 (1·2단계)

홀드아웃1 이 드러낸 세 유형 중 둘을 열었다.

**1단계 누적 기간** — `1~11월` 을 `(202401, 202411)` 로 풀어 월 자료를 합산.
수준값만 열고 증감률은 닫아뒀다.

**2단계 분기** — `2022년 2분기` → `202202`, `prd_se=Q`.
그리고 **표의 수록 주기를 처음으로 메타에 담았다**(`getMeta type=PRD`).

주기 가드는 **작동했다.**

| | 홀1 | 홀3 |
|---|---|---|
| 분기·월 주장 | 21 | 24 |
| 답할 수 없는 표로 가던 것 | 18 (86%) | 18 (75%) |

표 245개 중 **연간 전용 115개(47%), 격년 69개(28%)** — 75% 가 분기·월을 못 준다.
분기 주장이 어긋나는 것은 구조적으로 예정돼 있었다.

**그러나 정밀도는 개선하지 못했다.** 홀3 확정 4건이 전부 불일치였고,
**넷 다 1·2단계가 겨냥한 유형이 아니었다.**

## 마지막 측정 — 검색은 병목이 아니다

팀원 제안(단계별 좁히기, 공식 통합검색 후보 추가, Recall 먼저 측정)을 코드와 대조했다.
**구조는 이미 제안과 거의 같았다.** 진짜 빠진 것은 공식검색 미사용과 지역 축 부재였다.

그래서 공식 통합검색으로 **독립 후보**를 만들어 우리 것과 섞고, 출처를 가린 채 12건을 라벨했다.

| | |
|---|---|
| 공식검색 후보 | 806행 · 고유 표 351 |
| 우리 후보와 겹침 | **11 / 793** |
| 라벨 결과 정답 있음 | 4 / 12 |
| **`없음`** | **8 / 12** |
| 정답 선택지 출처 | **`ours` 6개 · `official` 0개** |
| 우리 후보에서의 순위 | 1위 4개 · 2위 2개 |

**세 가지가 나왔다.**

1. **검색은 병목이 아니다.** 정답이 존재할 때 우리 후보 **1~2위**에 있었다.
2. **공식 통합검색은 도움이 안 된다.** 782개를 새로 가져왔는데 정답은 0개다.
   키워드 검색이라 노이즈만 늘었다. **가정하지 않고 재봐서 알았다.**
3. **8/12 가 KOSIS 에 아예 없다.** 이게 가장 큰 제약이다.

`없음` 8건 중 4건이 같은 CES 문장이므로 비율은 부풀려져 있다.
그래도 로봇산업실태조사·WTO 순위·완성차 수출처럼 **구조적으로 없는 것**이 나머지다.
