# 실제 뉴스 URL E2E 서비스 승격 정책

## 목적

좌표 골드 평가에서 높은 Top-k 성능을 보인 엔진도 실제 기사 본문 수집, HCX 주장 추출, 기간·단위 정규화, KOSIS API 조회가 연속으로 연결되면 실패할 수 있습니다. 따라서 서비스 승격은 잠금 URL셋의 E2E 결과로 별도 판정합니다.

## 잠금 원칙

- 평가 전에 URL 목록과 SHA-256을 기록합니다.
- 평가가 시작된 뒤 URL을 교체하거나 제외하지 않습니다.
- 본문 수집 실패도 실패율에 포함합니다.
- 잠금셋에서 발견한 사례에 맞춰 규칙을 수정한 뒤 같은 셋으로 성능 향상을 주장하지 않습니다.
- 수정이 필요하면 별도 개발 URL셋에서 개선하고 새로운 잠금 URL셋으로 재평가합니다.

## PoC 승격 기준

| 항목 | 기준 |
|---|---:|
| 잠금 URL | 30건 이상 |
| 기사 본문 수집 성공률 | 90% 이상 |
| 본문 수집 성공 건 중 파이프라인 작업 성공률 | 95% 이상 |
| 전체 측정값 중 공식 근거 선택률 | 10% 이상 |
| 공식 근거가 한 개 이상 생성된 기사 | 5건 이상 |
| 실행시간 p95 | 600초 이하 |
| 엔진 fingerprint | 단일 동결 SHA만 사용 |
| 수치·측정값 | 1개 이상 추출 |
| KOSIS-ready 측정값 | 1개 이상 생성 |

모든 기준을 충족해도 `MISMATCH_REVIEW_REQUIRED` 표본은 정확한 표·ITEM·OBJ·기간과 통계 개정 여부를 사람이 마지막으로 확인합니다. `UNRESOLVED`는 실패를 숨기는 값이 아니라, 오판을 막기 위해 공식 좌표를 확정하지 못했음을 나타내는 정상적인 안전 결과입니다.

## 자동 산출물

- `qa_summary.json`: 본문 수집·작업 성공률, 판정 분포, 응답시간
- `funnel_audit.json`: READY·ENRICH·REJECT, KOSIS 후보 판정 코드
- `funnel_details.csv`: 기사별 퍼널 결과
- `service_readiness.json`: 승격 기준별 PASS/FAIL
- `evidence_sha256.txt`: 잠금 목록·코드·결과 증거 SHA-256

`service_readiness.json`이 `PASS`일 때만 서비스 API와 프론트 후보를 새 동결 버전으로 승격합니다.
