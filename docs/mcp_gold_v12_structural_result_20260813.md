# MCP gold v12 구조 검증 결과 (2026-08-13)

## 결론

v11의 Top-10 메타데이터 BGE 리랭커 뒤에만 규칙을 추가하는 대신, 상류 후보
Top-20 전체를 SQLite 공식 스키마로 다시 검사하는 편이 더 효과적이었다.

논리적 파이프라인은 다음과 같다.

1. 비정형 검색: lexical/BGE/Reranker가 관련 KOSIS 표 후보 Top-20을 만든다.
2. 정형 검증: SQLite가 수록주기, ITEM, OBJ 값, 미요청 모집단·계절조정 범위를 검사한다.
3. 좌표 선택: ITEM과 OBJ를 분리 채점한 뒤 하나의 좌표를 선택한다.
4. KOSIS API: 확정 좌표의 실제 값만 조회한다.

## 평가 데이터 감사

기존 좌표 감사 PASS 119건은 실제 코드 존재만 확인했으며 의미 오류를 걸러내지
못했다. 2차 의미 감사에서는 42건만 PASS였고, 다음의 명백한 오염이 추가로
발견됐다.

- 수입액 기사에 수출액 ITEM을 지정한 골드
- 자동차 수출대수 기사에 수출액 ITEM을 지정한 골드
- HCX 주기·대상기간이 비었는데 골드 기간만 채워진 행

해당 모순과 기간 누락까지 보수적으로 제외한 진단 부분집합은 23건이다. 두
부분집합 모두 규칙 감사 결과일 뿐 독립적인 사람/MCP 좌표 골드를 대체하지 않는다.

## v11에서 발견한 구현 문제

- 원래 검색 후보의 정답 표 재현율은 Top-10 92.86%, Top-20 97.62%였지만 v11은
  메타데이터 리랭커 입력을 Top-10으로 잘랐다.
- v11 개발 SQLite는 ITEM·OBJ를 담았지만 `kosis_periodicities`가 0건이었다.
- 평가기가 실제 선택 주기보다 `coordinate_prd_se=M|Q|Y` 같은 표 능력 집합을 먼저
  읽어 주기 정확도를 잘못 채점할 수 있었다.

## 동일 입력 CPU 재평가

| 평가 | v11 동등 기준 | v12 Top-20 + 구조 가중치 0.8 |
|---|---:|---:|
| 감사 42건 표 정확도 | 71.43% | 88.10% |
| 감사 42건 ITEM·OBJ 정확도 | 57.14% | 73.81% |
| 감사 42건 전체 좌표 정확도 | 38.10% | 52.38% |
| 감사 42건 표 Top-5 | 85.71% | 95.24% |
| 감사 42건 표 Top-10 | 92.86% | 97.62% |
| 보수 23건 전체 좌표 정확도 | 65.22% | 91.30% |

감사 42건에서 기존 정답을 오답으로 바꾼 회귀 없이 6건을 복구했다. 대표 복구는
다음과 같다.

- 청년 고용률: 이민자 연령표 → 일반 연령별 경제활동인구 총괄
- 일반 취업자·실업률: 계절조정/교육정도 표 → 성별 경제활동인구 총괄

## 해석 제한

이 결과는 독립 홀드아웃이 아니라 기존 MCP gold 200의 규칙 감사 부분집합에서 얻은
개발 결과다. 규칙 가중치 0.8은 이 결과만으로 최종 확정하지 않는다. 다음 GPU 실험은
Top-20 BGE 메타데이터 리랭커에 동일 정형 검증을 적용하고, 최종 판단은 별도 실제
KOSIS MCP 좌표 골드에서 한다.
