# 일반화 감사

## 평가셋 사용 원칙

- v33 blind100은 평가 전용으로 잠갔으며 결과를 확인한 뒤 개발 규칙에 사용하지 않았습니다.
- 후속 blind100도 각각 동결 코드로 한 번 평가한 뒤 다시 튜닝하지 않았습니다.
- v64 개발 600건은 blind가 아닙니다. 지도형 exact mapping cache를 같은 600건에 재대입한 개발 수치입니다.
- v65 blind100은 v64 동결 뒤 새로 구성해 한 번만 평가했고, 결과를 v64 수정에 사용하지 않았습니다.
- v66 조선일보 URL50은 원본 `chosun_full.csv`에서 잠근 E2E QA이며 중간 결과로 규칙을 수정하지 않았습니다.

가장 큰 병목은 조사명·작성기관·통계표 계열을 포함한 Stage A 표 recall이었습니다.

## 신규 blind100 변화

| 동결 후보 평가 | ITEM Top-5 | 전체 좌표 Top-5 | 해석 |
|---|---:|---:|---|
| v34 후보 → v35 blind100 | 71% | 68% | 목표 미달 |
| v36 동결 → v37 blind100 | 65% | 64% | 회귀 |
| v39 동결 → v40 blind100 | 56% | 50% | 큰 일반화 실패 |
| v42 동결 → v43 blind100 | 73% | 70% | 좌표 목표만 도달 |
| v64 동결 → v65 blind100 | 58% | 54% | 최종 일회 평가, 목표 미달 |

여러 신규 blind에서 성능 변동이 컸으므로 작은 개발셋 상승이나 지도형 cache 재대입 결과로 일반화 완료를 주장할 수 없습니다.

## v64 개발 600건 재대입

표가 분리된 개발 600건의 cache 적용 전 성능은 ITEM Top-5 64.7%, 전체 좌표 Top-5 60.3%였습니다. v64는 이 600건에서 지도형 mapping cache 522개 항목을 만들고 같은 행에 재대입해 다음 수치를 기록했습니다.

| 지표 | 적용 전 Top-5 | v64 재대입 Top-5 |
|---|---:|---:|
| ITEM | 64.7% | 90.3% |
| 전체 좌표 | 60.3% | 90.2% |

이 수치는 `SUPERVISED_EXACT_MAPPING_CACHE_RESUBSTITUTION`이며 블라인드 일반화 성능이 아닙니다. blind label은 cache에 사용하지 않았습니다.

| 항목 | 결과 |
|---|---:|
| 기사 수집 성공 | 50/50 |
| 작업 성공 | 50/50 |
| 공식 근거 선택 | 11/96 (11.46%) |
| 공식 근거 기사 | 5건 |
| 작업시간 p95 | 290.36초 |

서비스 준비도 사전 기준은 모두 통과했습니다. 다만 `MATCH` 11개보다 `UNRESOLVED` 252개가 훨씬 많으므로, 이는 실행 안정성과 최소 근거 커버리지 통과이지 일반 뉴스 팩트체크 정확도 100%를 뜻하지 않습니다.

## 결론

- v64를 최종 PoC 데모·서비스 후보로 유지합니다.
- 대표 일반화 검색 수치는 v65 blind100 ITEM Top-5 58%, 좌표 Top-5 54%로 공개합니다.
- 개발 600건 90.3%·90.2%는 반드시 재대입 개발 성능이라고 표시합니다.
- v66 URL50 서비스 QA는 `PASS`, `promotion_allowed=true`입니다.
- 프로젝트는 추가 튜닝 없이 이 결과와 한계를 함께 공개하고 마감합니다.

근거는 `evaluation/generalization_audit/`, `evaluation/v65_blind100/`, `evaluation/v66_locked_url50/`에 보존합니다.
