# v43 E2E 일반 회귀 수정 후보

이 디렉터리는 동결 `v42_service_20260823_r1`을 직접 수정하지 않는 overlay 개발본입니다. 현재 실행 중인 신규 URL 30건 결과에는 적용하지 않습니다.

## 수정 1: 한국어 혼합 단위 숫자 정규화

기존 파서는 `5천121만7천221`을 각 단위의 단순 합으로 계산해 `1,222,221`로 만들었습니다. 새 파서는 `조·억·만`을 구간 경계로, `천·백`을 구간 내부 승수로 처리합니다.

- `5천121만7천221` → `51,217,221`
- `1천24만4천550` → `10,244,550`
- `1조7240억` → `1,724,000,000,000`
- `3억5천만` → `350,000,000`

HCX가 잘못 환산한 경우에도 원문 `measurement_text`와 규칙 기반 후보를 대조해 올바른 값으로 복구합니다.

## 수정 2: 비교 기간 필드 어댑터

Stage C 좌표 계약은 이전 시점을 `previous_period`에 저장하지만 값 검증기는 `comparison_period`를 읽습니다. v42 어댑터가 `previous_period`만 기록해, 실제로 `2024`가 존재해도 `COMPARISON_PERIOD_MISSING`으로 보류되는 문제가 있었습니다.

후보 검증 행에 두 필드를 함께 보존합니다.

- `previous_period`: 좌표 공개 계약 호환
- `comparison_period`: `kosis_verify_claim_values.verify_row` 입력 계약

## 수정 3: 지표 단위 충돌과 파생률 분기의 우선순위

`소매판매액 지수 0.5% 증가`처럼 수준 지표의 증감률을 검증하는 경우에는 지수 수준값의 두 시점을 조회해 증감률을 계산해야 합니다. v42는 `INDICATOR_UNIT_CONFLICT` 분기가 먼저 실행되면 파생 계산 분기를 건너뛰어 `direct` 매핑과 `UNIT_UNCERTAIN`을 만들었습니다.

비교 기간이 확인된 `rate_change`·`absolute_change`는 수준 ITEM을 조회하는 파생 매핑 후보로 전환합니다. 직접 공표된 증감률 ITEM도 후보로 남기기 위해 `allowed_mapping_types`는 `direct|rate_from_level` 또는 `direct|difference_from_level`을 유지합니다.

개별 브랜드·상품 가격은 이 분기로 승격하지 않습니다. `INDIVIDUAL_PRODUCT_PRICE`를 먼저 적용해 KOSIS 직접 검증 대상에서 제외합니다.

## 검증 원칙

- 현재 잠금 URL 30건은 재실행하거나 결과를 교체하지 않습니다.
- 이 수정은 합성 단위 테스트와 기존 비잠금 개발 URL셋에서 검증합니다.
- 개발 성능을 확인한 뒤 완전히 새로운 URL 잠금셋으로만 일반화 성능을 평가합니다.
