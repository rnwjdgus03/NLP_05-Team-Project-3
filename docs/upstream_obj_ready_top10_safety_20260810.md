# 상류 검색·OBJ READY·Top-10 안전장치 (2026-08-10)

## 변경 목적

KOSIS 표 검색 단계의 오답 후보를 줄이고, 실제 OBJ 축이 모두 일치하지 않은
좌표와 Top-10 폴백 좌표가 자동 `READY`가 되는 경로를 차단한다.

## 적용 내용

1. 상류 표 검색
   - 기사에 정식 조사명이 없어도 비정규직·실업률·고용률 등 강한 계열 단서로
     공식 조사군을 추론한다.
   - 조사명, 성별·연령·교육정도·지역·국가 축, 측정 단위와 표의 지표 형태를
     함께 점수화한다.
   - 인원 수 주장은 임금·취업시간 표보다 규모·인원 표를 우선한다.
   - 비정규직 총괄 주장에 시간제·한시적 하위 유형 표가 앞서는 것을 억제한다.

2. `READY` 전 OBJ 완전 일치 게이트
   - 구조화된 성별·지역·연령·교육정도·국가·품목 대상을 KOSIS의 실제 OBJ 축
     이름과 값에 각각 대조한다.
   - 하나라도 빠지거나 다른 종류의 축에 붙으면 `NEEDS_CONFIRMATION`으로 내린다.
   - 축 이름이 없는 구형 좌표 인덱스도 자동 `READY`를 허용하지 않는다.
   - 결과 CSV에는 `obj_axis_gate_*` 진단 필드를 남긴다.

3. Top-10 폴백
   - Top-5의 기술적 실패 건에만 기존처럼 제한적으로 실행한다.
   - 6~10위에서 회수한 후보가 검증기에서 `READY` 또는 `PROVISIONAL`이어도 최종
     상태를 `NEEDS_CONFIRMATION`으로 내리고
     `TOP10_FALLBACK_REQUIRES_CONFIRMATION`을 기록한다.
   - 원래 상태는 `topk_fallback_status`, 차단 여부는
     `topk_fallback_auto_ready_blocked`에 보존한다.

## 검증

- 107,138개 KOSIS 표 요약을 사용한 성별 비정규직 인원 주장 스모크 검색:
  공식 표 `101/DT_1DE7106S`가 기존 Top-10 7위에서 Top-5 3위로 상승했다.

## 실행 주의

OBJ 완전 일치 게이트는 실제 축 이름 메타데이터를 요구한다. 축 이름을 담지 않은
기존 Chroma 좌표 인덱스는 재사용하지 말고 현행 `kosis-meta-coordinates-v2`
스키마로 다시 생성해야 한다.
