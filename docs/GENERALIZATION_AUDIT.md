# 일반화 감사

## 평가셋 사용 원칙

- v33 blind100은 평가 전용으로 잠갔으며 결과를 확인한 뒤 개발 규칙에 사용하지 않습니다.
- 후속 blind100도 각각 동결 코드로 한 번 평가한 뒤 다시 튜닝하지 않습니다.
- v62 개발 600건은 blind가 아닙니다. 과거 골드 1,099개 표의 ID를 제외했지만 정답 label은 사용하지 않은 별도 개발 진단입니다.
- 조선일보 URL50은 잠금 E2E 평가이며 결과를 보고 규칙을 추가하지 않습니다.

## v33 실패 35건 퍼널

| 단계 | 건수 |
|---|---:|
| Stage A 표 검색 실패 | 20 |
| Stage B/C ITEM 실패 | 11 |
| Stage B/C OBJ 실패 | 4 |
| 성공 | 65 |

가장 큰 병목은 조사명·작성기관·통계표 계열을 포함한 Stage A 표 recall이었습니다.

## 후속 blind100 변화

| 동결 후보 평가 | ITEM Top-5 | 전체 좌표 Top-5 | 해석 |
|---|---:|---:|---|
| v34 후보 → v35 blind100 | 71% | 68% | 목표 미달 |
| v36 동결 → v37 blind100 | 65% | 64% | 회귀 |
| v39 동결 → v40 blind100 | 56% | 50% | 큰 일반화 실패 |
| v42 동결 → v43 blind100 | 73% | 70% | 좌표 목표만 도달 |

여러 번의 신규 blind에서 성능 변동이 컸으므로, 작은 개발셋의 상승만으로 일반화 완료를 주장할 수 없습니다.

## v60과 표 분리 개발 600건

v60은 개발 300건에서 ITEM Top-5 77.3%, 좌표 Top-5 74.3%로 PoC 중단 기준을 통과했습니다. 그러나 과거 골드 통계표와 중복이 0개인 v62 개발 600건에서는 다음과 같았습니다.

| 지표 | Top-1 | Top-3 | Top-5 |
|---|---:|---:|---:|
| ITEM | 41.8% | 60.0% | 64.7% |
| 전체 좌표 | 38.7% | 55.2% | 60.3% |

실패 퍼널은 Stage A 132건, ITEM 85건, OBJ 26건, 성공 357건입니다. Stage A Top-30은 78.0%였고, 107건은 raw recall 단계에서 이미 정답 표를 찾지 못했습니다.

## 결론

- v60은 발표·서비스 PoC 후보로 유지합니다.
- 대표 수치는 `개발 300건 Top-5`라고 명시합니다.
- 독립 표에서 성능이 12~14%p 하락했으므로 일반화 성능이 목표를 충족했다고 주장하지 않습니다.
- 추가 튜닝보다 잠금 URL E2E의 실제 커버리지·실패율·근거 품질을 최종 서비스 판단 근거로 사용합니다.

근거는 `evaluation/generalization_audit/`에 보존합니다.
