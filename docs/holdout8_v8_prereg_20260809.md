# holdout8 v8 사전등록

- 입력 기사·문장·claim-context·HCX measurement는 v7과 같은 동결 체크포인트를 사용한다.
- HCX API는 다시 호출하지 않는다.
- KOSIS 표 검색과 좌표 검색만 재실행한다.
- 평가 골드는 실행 번들에 포함하지 않는다.

## 변경 사항

1. 표 검색에서 주장에 없는 국가·지역·연령·성별·학력·계절조정 축을 감점한다.
2. 주장 주기와 표 제목의 월·분기·연간 표현이 맞으면 가점한다.
3. 명시적 종료 범위가 아닌 과거 기준 설명 연도는 현행 표 감점에 사용하지 않는다.
4. 경상수지와 국제수지의 공식 통계 계열 관계를 검색 확장어로 사용한다.
5. 하이브리드 Top-20에 어휘 상위 10개 표를 보존한다.
6. Top-5/Top-10 표 군별로 표당 최소 3개 좌표를 보존하고 전역 좌표 컷오프를 30개로 넓힌다.
7. 정규직과 비정규직 OBJ는 정확히 구분한다.
8. 표 Recall은 `table_rank`, 좌표 선택은 `candidate_rank`로 분리 평가한다.

## 판정 지표

- MCP 실제 골드 표 Recall@1/5/10
- 최종 표 정확도, ITEM 정확도, 기간 정확도, 완전 좌표 정확도
- Top-5/Top-10 선택 일치율
- OBJ target 일치 수
- API_ERROR 수
