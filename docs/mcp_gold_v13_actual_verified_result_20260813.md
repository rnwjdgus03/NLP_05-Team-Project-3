# MCP gold v13 실제조회 검증 결과 (2026-08-13)

## 결론

v13은 v12의 `의미 검색 → SQLite 구조 검증 → ITEM 우선 → OBJ 선택`을 다음처럼
수정했다.

1. 주장에 지역 대상이 없으면 시도·시군구·9개도·39개시 세분 표를 감점한다.
2. 지표가 통계표명의 중심 개념으로 시작하는 표를 우선한다.
3. 지표 개념이 KOSIS ITEM이 아니라 OBJ 값으로 표현되는 표도 정답 후보로 인정한다.
4. ITEM 후보 수 제한을 전체 후보에 적용하지 않고 통계표별로 적용한다.
5. 최종 좌표는 ITEM과 OBJ의 공동 개념 일치, typed-axis 일치, 표 순위를 함께 비교한다.

원본 Top-20 후보에서 재실행한 결과, KOSIS MCP 실제 조회와 주장 수치 재현을 모두
통과한 엄격 8행에서 완전 좌표 정확도 100%를 기록했다. 그러나 8행은 기존 개발
골드에서 추린 표본이고 중복 주장이 포함돼 있으므로 독립 일반화 성능으로 보고하지
않는다.

## 실제 조회 골드 재감사

기존 의미 감사 PASS 23행의 좌표를 KOSIS MCP로 `search → validate → get_data` 순서로
다시 확인했다.

- 12개 고유 `기관-표-ITEM-OBJ-주기` 좌표에서 공식 수치가 반환됐다.
- 23행 모두 골드의 현재값·이전값·단위와 KOSIS 실제 응답이 일치했다.
- 하지만 공식 좌표와 값이 존재한다는 사실만으로 기사 주장과의 의미 일치가
  증명되지는 않았다.
- 기사 claim 값을 실제 응답에서 지정된 계산식으로 재현하는 추가 게이트를 적용하자
  23행 중 8행만 PASS, 15행은 REVIEW가 됐다.

대표적인 REVIEW는 다음과 같다.

- 수입차 판매량 감소율을 전체 수입액 증감률로 바꾼 행
- 미국 실업률을 한국 전체 실업률 좌표에 연결한 행
- 제조업 취업자 비중을 전체 취업자 수에 연결한 행
- 경제성장률 전망을 수출액 증가율에 연결한 행

따라서 `mcp_actual_verified_23.csv`는 좌표 존재·값 확인용이며,
`mcp_actual_semantic_verified.csv`만 주장 의미까지 확인한 개발 회귀 표본이다.

## 남은 병목

- 엄격 실제조회 표본이 8행으로 너무 작고 수출 주장에 편중돼 있다.
- 42행에서 기간 정확도는 64.29%로 남아 있어 상대 월·전년동월·연간 누적 기간
  추출이 다음 주요 병목이다.
- 현재 평가는 기존 200행 개발 골드에서 추린 부분집합이므로 새 기사 기반의 미사용
  홀드아웃에서 다시 측정해야 한다.
- 자동 READY 정밀도와 최종 verdict 정확도는 아직 이 결과로 증명되지 않는다.
