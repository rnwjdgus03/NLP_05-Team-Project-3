## 사전등록 판정

### 1. target-bearing claim을 aggregate로 READY 확정하지 않는다 — 통과

mapping `READY`는 1건뿐이고 `claim_target_terms`가 비어 있었다. 따라서 target-bearing claim이 aggregate OBJ로 READY 확정된 건은 0건이다.

### 2. exact target이 있으면 우선하고, 없으면 확정하지 않는다 — 통과

`chroma_stats.csv`에서 target-bearing measurement는 21건이었다.

- 후보 풀에 exact OBJ target이 있던 5건: **5/5 모두 rank 1에서 `obj_target_match=True`**
- exact target 후보가 없던 16건: **READY 0건**
  - 이 중 15건은 비일치 후보만 남았고, 1건은 최종 후보가 없었다.

즉 검색·검증 사이의 target 안전장치는 의도대로 동작했다.

### 3. target 관련 거짓 불일치 0건 — 형식상 통과, 증거력 낮음

verified 결과는 1건이며 `MAPPING_TYPE_UNSUPPORTED`로 `판단불가`였다. `불일치`는 0건이지만 `일치`도 0건이므로, 이 조건은 안전성 확인에만 쓴다.

### 4. API 오류 0건 — 통과

validate와 실제값 검증 모두 API 오류가 0이었다. 낮은 확정률은 네트워크 장애가 아니라 후보·메타·의미 게이트 문제다.

### 5. 첫 50건 회귀 — 저장 산출물·테스트 기준 유지

`data/shared_20260802/`의 현재 저장 산출물은 평가 88건, `CONFIRMED` 17건, verified 17건, `MATCH` 7건, `VALUE_MISMATCH` 0건이다. 사전등록 문구의 기준 16/7보다 저장 산출물의 confirmed가 1건 많다. target-aware 변경 직후 전체 테스트는 **1,070 passed, 1 skipped**였고 target 선택 회귀 테스트도 통과했다.

이번 GPU 반환 ZIP에는 첫 50건 재실행 산출물이 없으므로, 첫 50건의 운영 재실행 비교값은 새로 주장하지 않는다.

## 유일한 READY의 오류 성격

주장은 `전월보다는 2.4% 올랐다`이며 문맥상 지표는 **수입 물가 증감률**이다. 선택된 표는 `월별 소비자물가 등락률`, ITEM은 `전월비`, OBJ는 `총지수`였다.

이는 분류축 문제가 아니라 **표 의미 불일치**다. 실제값 검증기는 `mapping_type`이 비어 있어 `MAPPING_TYPE_UNSUPPORTED`로 차단했다. 결과적으로 잘못된 값 일치·불일치 판정은 생성되지 않았다.

## 새로 드러난 병목

1. **target term 과추출**
   - `고용`, `실업률`, `GDP`, `수출`, `가장`, `1월`, `9월` 등이 분류 대상처럼 검출됐다.
   - target 안전장치는 오확정을 막았지만, 잘못 잡힌 target도 우선순위 신호가 된다.

2. **표 의미 게이트 부족**
   - 수입물가 주장이 소비자물가 표로 READY가 됐다.
   - indicator와 표 이름·기관·통계 도메인의 교차 일치가 READY 전에 더 강하게 확인돼야 한다.

3. **mapping type 복구 부족**
   - `value_type=증감률`, `direction=증가`, `change_base=전월`인데 `mapping_type`이 비어 있었다.
   - 명백한 전월비·전년동월비는 구조 필드에서 결정적으로 복구할 수 있다.

4. **상류 게이트의 낮은 통과율**
   - 389 measurement 중 60건만 잠긴 평가 집합에 들어왔다(15.4%).
   - 이 홀드아웃은 해외·기업·시장 통계가 많아 KOSIS 범위 밖 주장 비중도 높다.

## 다음 작업

홀드아웃5에는 더 이상 맞춤 수정하지 않는다. 다음 개발·평가 순서는 아래와 같다.

1. target term을 `지역·국가·산업·품목·인구집단`으로 한정하고, 지표어·시점·최상급 표현을 제외한다.
2. READY 전에 `claim indicator ↔ table name/category/statistics agency` 의미 게이트를 추가한다.
3. 구조 필드로 명백한 `mapping_type`을 복구한다.
