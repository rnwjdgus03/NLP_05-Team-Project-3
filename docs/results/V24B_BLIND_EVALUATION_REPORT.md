# v24b 동결 블라인드 좌표 평가 보고서

## 결론

v24b를 동결한 뒤 개발 기사와 ID·URL·claim이 겹치지 않는 2026년 공식 보도자료 9건에서 31개 측정값을 만들고, KOSIS Open API 실제 조회로 좌표와 값을 잠근 다음 한 번만 평가했다.

전체 31건을 분모로 계산한 Full 좌표 정확도는 Top-1 `0/31 (0.0%)`, Top-3·5·10 `8/31 (25.8%)`, MRR `0.1290`이다. 표와 ITEM은 Top-3 `16/31 (51.6%)`였지만 정확한 OBJ까지 맞춘 건은 8건이었다. 최종 값 검증 단계의 확정 판정은 `0/31`이다.

따라서 v24b는 기존 개발 골드에서는 개선됐지만 신규 고용·물가 자료에 안정적으로 일반화됐다고 볼 수 없다. 이번 블라인드 평가는 실패 원인을 세 단계로 분리해 다음 버전의 우선순위를 명확히 했다.

## 신규 골드 구성

| 영역 | 문서 | 측정값 | KOSIS 표 |
|---|---:|---:|---|
| 2026년 1~4월 소비자물가동향 | 4 | 16 | `DT_1J22042` 월별 소비자물가 등락률 |
| 2026년 1~5월 고용동향 | 5 | 10 | `DT_1DA7001S` 성별 경제활동인구 총괄 |
| 2026년 1~5월 청년 실업률 | 5개 문서 내 측정값 | 5 | `DT_1DA7002S` 연령별 경제활동인구 총괄 |
| 합계 | 9 | 31 | 3개 표 |

31개 모두 KOSIS Open API에서 `org_id + tbl_id + ITEM + OBJ + period`가 정확히 한 행으로 반환됐고, 공식 보도자료의 값과 허용 오차 안에서 일치했다.

기사·URL·claim ID는 개발셋과 분리했다. 다만 표 수준으로는 10건이 기존 개발 골드에 있던 `DT_1DA7001S`를 재사용한다. 표까지 겹치지 않는 21건의 Full Top-3는 `8/21 (38.1%)`이다. 따라서 이 자료는 기사 분리 블라인드이면서 일부 표 재사용 평가이며, 완전한 표군 독립 테스트로 과장하면 안 된다.

## 전체 31건 기준 성능

기존 평가기는 예측 패킷이 없는 5건을 분모에서 제외해 `8/26=30.8%`로 표시했다. 블라인드 보고에서는 누락도 실패이므로 31건 전체를 분모로 다시 계산했다.

| 평가 수준 | Top-1 | Top-3 | Top-5 | Top-10 | MRR |
|---|---:|---:|---:|---:|---:|
| 표 | 0/31 (0.0%) | 16/31 (51.6%) | 16/31 (51.6%) | 16/31 (51.6%) | 0.2366 |
| ITEM | 0/31 (0.0%) | 16/31 (51.6%) | 16/31 (51.6%) | 16/31 (51.6%) | 0.2366 |
| 좌표(표+ITEM+OBJ) | 0/31 (0.0%) | 8/31 (25.8%) | 8/31 (25.8%) | 8/31 (25.8%) | 0.1290 |
| Full(+주기+기간) | 0/31 (0.0%) | 8/31 (25.8%) | 8/31 (25.8%) | 8/31 (25.8%) | 0.1290 |

Full Top-3의 행 단위 Wilson 95% 구간은 약 `13.7%~43.2%`, 표 Top-3는 `34.8%~68.0%`다. 하지만 31개 측정값이 9개 문서와 3개 표에 군집돼 있으므로 이 구간은 기술적 참고값일 뿐 독립 표본 추론으로 해석하면 안 된다.

도메인별 차이가 매우 크다.

- 소비자물가 16건: 표·ITEM Top-3 `16/16`, Full Top-3 `8/16`
- 고용 15건: 표·ITEM·Full Top-3 모두 `0/15`
- 최종 값 판정: 26개 패킷 전부 `UNRESOLVED`, 나머지 5건은 패킷 없음

## 실패 퍼널

| 단계 | 건수 | 설명 |
|---|---:|---|
| Full 좌표 성공 | 8 | 농산물·석유류 제외 및 생활물가 OBJ, 모두 최종 2위 |
| OBJ 실패 | 8 | 물가 표와 ITEM은 찾았지만 기본 `총지수(OBJ=0)`를 선택하지 못함 |
| Stage A 정답 표 미검색 | 10 | 전체·청년 실업률 정답 표가 Top-10 표 후보에 없음 |
| 최종 패킷 없음 | 5 | 취업자 수 계열이 Stage A/B에서 좌표를 만들지 못함 |

### 1. 고용 표 검색 실패

Stage A의 표 검색 문서는 주로 표명·조사명·분류 경로로 구성된다. 정답 표명인 `성별 경제활동인구 총괄`, `연령별 경제활동인구 총괄`에는 `실업률`이나 `취업자`가 직접 드러나지 않는다. 반면 오답인 `고용보조지표(전체)` 등에는 질의 단어가 표명에 나타나므로 상위로 올라왔다.

다음 버전에서는 표 검색 문서에 해당 표의 대표 ITEM 이름을 제한적으로 포함하거나, PostgreSQL ITEM 역색인에서 ITEM 후보 표를 별도 recall 채널로 합쳐야 한다. ITEM 전체 조합을 다시 벡터 문서화할 필요는 없다.

### 2. 기본 총계 OBJ 실패

`농산물및석유류제외지수`, `생활물가지수`처럼 대상어가 명시된 8건은 OBJ를 맞췄지만, 단순 `소비자물가지수` 8건은 공식 기본값인 `총지수(0)`를 고르지 못했다.

다음 버전에서는 명시적 세부 OBJ가 없고 표의 축에 공식 `계·총지수·전체`가 존재할 때 이를 기본 좌표 후보로 보존하되, 기사에 세부 대상어가 있으면 기본 총계를 억제하는 규칙이 필요하다.

### 3. 월 범위 파서 오류

PostgreSQL에는 다음처럼 정상 범위가 저장돼 있다.

```text
DT_1J22042  M:1965.02~2026.07
DT_1DA7001S M:1999.06~2026.07
DT_1DA7002S M:1999.06~2026.07
```

그러나 `run_kosis_top5_verification.py::_period_in_range`의 정규식은 점이 포함된 `2026.07`을 6자리 월로 정규화하지 못하고 `2026`만 추출한다. 이후 `202601 <= 2026` 문자열 비교가 거짓이 되어 모든 후보를 `PERIODICITY_NOT_AVAILABLE`로 처리했다. 실제로는 신규 골드를 만들 때 동일 좌표의 KOSIS API 31건이 모두 정상 반환됐다.

이 문제 때문에 좌표 Top-k에서 성공한 8건도 최종 값 판정은 판단불가가 됐다. 다음 버전에서는 `YYYY.MM`, `YYYY-MM`, `YYYYMM`을 주기별로 동일 형식으로 정규화하는 단위 테스트를 먼저 추가해야 한다.

### 4. MCP fallback

블라인드 본 실행에서 MCP 31건은 `mcp_error`로 끝나 패킷에 편입되지 않았다. 실행 후 같은 동결 코드로 한 건을 진단 재현했을 때 MCP 서비스 호출 자체는 정상화됐지만, PostgreSQL 게이트에서 `period_range_unconfirmed`와 `period_not_exact`로 좌표 0건을 반환했다. 따라서 transient 오류만 없애도 현재 월 범위 판서가 고쳐지기 전에는 fallback이 회복되지 않는다.

## 다음 순서

이번 결과를 보고 v24b를 다시 튜닝하거나 같은 블라인드셋을 개발셋처럼 반복 사용하면 안 된다. 권장 순서는 다음과 같다.

1. 월 범위 파서를 수정하고 점·하이픈·무구분 월 범위 단위 테스트를 추가한다.
2. Stage A에 `대표 ITEM → 표`의 별도 lexical recall 채널을 추가한다.
3. OBJ 대상어가 없을 때 공식 총계 축값을 보존하는 기본값 정책을 추가한다.
4. 기존 개발셋에서만 회귀 테스트하고 이번 31건은 감사셋으로 보관한다.
5. 수정본이 동결되면 또 다른 새 기사·새 표군 골드로 두 번째 블라인드 평가를 한다.
