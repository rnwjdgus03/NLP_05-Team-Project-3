# 자동 확정 9건 좌표 검수 (2026-07-31)

확정 집합 134건 중 파이프라인이 READY 로 자동 확정한 9건이 **정말 맞는 좌표인지** 본다.
값이 맞는지가 아니라 **좌표(표·항목·분류)가 그 주장을 재는 것인지**를 판정한다.

판정 기준
- **O** 좌표가 주장을 정확히 잰다
- **△** 개념은 맞지만 기간·정의·부호에 의심이 있다
- **X** 다른 것을 재고 있다 (오매핑)

---

## 1. O — 수출 총액

> 한국의 2024년 수출이 6838억 달러를 기록해 역대 최대실적을 달성했다

`DT_1R11006_FRM101` / 수출액 / objL1=**계** → KOSIS 6836.1억달러, 차이 0.028%

주장이 "수출 총액"이고 좌표도 총계다. 정확하다.
실버가 `SILVER_AMBIGUOUS` 인 이유는 `DT_1R11001_FRM101` 도 같은 값을 내기 때문인데,
둘 다 무역통계 계열이라 **어느 쪽이든 정답**이다. 모호성이 아니라 중복이다.

## 2. △ — 수출증가율 (기간 정의 의심)

> 2024년 1~9월 기준(WTO)으로 전 세계 수출순위 8위→6위, 상위 10대 수출국 중
> 가장 높은 수출증가율(+9.6%)

`DT_1R11001_FRM101` / 수출액 (rate_from_level) → KOSIS 8.13%, 차이 1.47%p

**좌표는 맞지만 기간이 다르다.** 주장은 명시적으로 **1~9월 누적 · WTO 기준**인데
KOSIS 조회는 연간이다. 시스템은 이걸 `REVISION_VINTAGE_RISK`(개정 위험)로 보류했는데,
**보류 결론은 맞고 사유는 틀렸다.** 실제 원인은 기간·기준 불일치다.

→ 개선 지점: `measurement_period` 가 "2024" 로 잡혔지만 주장은 "202401~202409" 다.

## 3. O — 수입 증감률

> 2024년에는 에너지 수입이 감소하면서 전체 수입이 전년 대비 1.6% 감소

`DT_1R11001_FRM101` / 수입액 / objL1=**총액** → KOSIS -1.68%, 차이 0.08%p

"전체 수입"에 "수입액 총액"이다. 정확하다. 0.08%p 차이는 반올림·개정 수준.

## 4. O — 반도체 수출액 (가장 확실)

> 반도체가 43.9% 증가한 1419억 달러를 기록

`DT_127005_005` / 수출액 / objL1=**반도체** → KOSIS 1420.9억달러, 차이 0.131%

품목까지 정확히 일치한다. 실버 `SILVER_UNIQUE` 로 값도 재현됐다. **가장 신뢰도 높은 건.**

## 5. O — 수입 증감률 (3번과 동일 지표, 다른 기사)

> 작년 한국의 수입액은 전년보다 1.6% 감소한 6320억달러로

`DT_1R11001_FRM101` / 수입액 / 총액 → -1.68%, 차이 0.08%p. 3번과 같은 판단.

## 6. O — 수입액 수준값

> (같은 문장) 6320억달러

`DT_1R11001_FRM101` / 수입액 / 총액 → KOSIS 6317.7억달러, 차이 0.037%. 정확하다.

## 7. X — 무역흑자를 수입액에 매핑 ★오매핑

> (같은 문장) 518억달러의 무역 흑자를 기록했다

`DT_1R11001_FRM101` / **수입액** / 총액 → KOSIS 6320억달러, 차이 **1,120%**

**무역수지 흑자를 수입액에 붙였다.** 완전히 다른 지표다.
`LIKELY_MISMAPPING` 가드가 판정 단계에서 잡아 '판단불가'로 뺐지만,
**좌표 자체는 READY 로 확정된 상태**다. 즉 확정 단계에서 걸렀어야 했다.

→ 한 문장에서 수입액·증감률·무역흑자 3개를 뽑았는데 셋 다 같은 좌표에 붙은 것이 원인.

## 8·9. O — 산업생산 전월비 (초기 판정 △ 에서 정정)

> 생산은 작년 9월(-0.4%)·10월(-0.2%)·11월(-0.4%) 등 3개월 연속 전월 대비 감소

`DT_1JH20202` / 계절조정지수 / objL1=**전산업생산지수**

### 초기 판정과 그것이 틀린 이유

처음에 "부호가 반대이고 개정으로 설명 불가"라고 적었다. **두 군데가 틀렸다.**

**(1) 검증기 계산은 정확했다.** 차이 1.01 을 보고 `claim=-0.4, actual=+0.61` 로 역산했는데,
실제 컬럼을 열어보니 `value=0.4`(부호 없음), `kosis_actual_raw=-0.6124` 였다.
KOSIS API 로 직접 계산한 202409 전월비도 **-0.61%** 로 검증기와 일치한다.
문제는 KOSIS 쪽이 아니라 **주장 쪽 부호가 빠진 것**이었다.

원문은 `9월(-0.4%)` 로 마이너스가 괄호 안에 있는데 추출은 크기만 저장했고,
'감소' 는 값에서 20자 넘게 떨어져 있어 기존 방향어 규칙(값 뒤 6자)이 닿지 않았다.
→ `signed_claim_value` 에 **원문 명시 마이너스 복원**을 추가해 고쳤다.
   수정 후 차이가 **1.01%p → 0.21%p** 로 줄었다.

**(2) 계절조정 시계열은 부호가 뒤집혀도 개정으로 설명된다.**
계절조정은 새 관측이 들어올 때마다 **과거 전체를 재추정**한다.
실제로 202410 은 기사 시점 -0.2% 였으나 현재 KOSIS 값은 +1.14% 다.
따라서 `REVISION_VINTAGE_RISK` 보류는 이 경우 **타당한 판단**이었고,
"보류가 판정 회피"라고 본 내 의심이 과했다.

**(3) `objL1=1` 은 전산업생산지수다** (메타 조회로 확인). 오매핑이 아니다.

## 확정된 개선 과제

| 우선순위 | 문제 | 근거 | 상태 |
|---|---|---|---|
| 1 | **한 문장의 measurement 들이 같은 표를 공유** | 7번 — 수입 증감률·수입액·무역흑자 3개가 모두 `DT_1R11001_FRM101` 에 붙었는데 이 표엔 수출액·수입액만 있고 **무역수지 항목이 없다** | 미해결 |
| 2 | 원문 명시 마이너스 손실 | 8번 — `9월(-0.4%)` 의 부호가 빠져 차이가 1.01%p 로 부풀었다 | **해결** (0.21%p) |
| 3 | 기간 정의 불일치 | 2번 — 주장은 1~9월 누적인데 `measurement_period=2024` | 미해결 |

1번이 남은 최대 과제다. 상류 표 검색이 **문장 단위**로 돌아서, 한 문장에서 나온
서로 다른 지표가 모두 같은 Top-5 표를 받는다. 무역수지는 애초에 다른 표에 있다.

## 이 검수에서 배운 것

LLM 검수가 **두 번 틀렸고 둘 다 실제 데이터 조회로 뒤집혔다.**

| 내 판단 | 실제 |
|---|---|
| "검증기가 +0.61 로 계산했다" | 검증기는 -0.61 로 정확히 계산. **claim 쪽 부호가 없었다** |
| "부호 반전은 개정으로 설명 불가" | 계절조정은 재추정으로 과거가 통째로 바뀐다. **보류가 타당** |

둘 다 **역산 추측**이었고, `kosis_period_used` / `kosis_actual_raw` 컬럼을 직접 열자
바로 뒤집혔다. → **추측으로 판정하지 말고 남은 컬럼을 먼저 볼 것.**
